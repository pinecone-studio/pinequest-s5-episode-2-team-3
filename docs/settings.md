# Тохиргоо ба нөөц (4-р хэсэг)

- Өдрийн зорилт эсвэл дээд хязгаар (50–10,000 мл) тохируулах, 10 секундын дотор буцаах
- Бүртгэл, тохиргоо `localStorage`-ийн `dusal-v1` түлхүүрт хадгалагдаж, вэбийг дахин нээхэд сэргэнэ
- Бүх мэдээллийг `dusal-backup-ОООО-СС-ӨӨ.json` файл болгон татах
- Нөөц файлыг шалгаж (5 MB хүртэл, JSON, бүтэц, давхардсан id), харьцуулалтыг харуулаад, баталгаажуулсны дараа сэргээх; сэргээснээ буцааж болно
- Хадгалалт бүтэлгүйтвэл, өгөгдөл эвдэрсэн бол, эсвэл өөр цонхонд өөрчлөгдсөн бол мэдэгдэнэ; хуучин мэдээллээр дарж бичихгүй. Эвдэрсэн өгөгдлийг зөвхөн нөөцөөс сэргээх үед, баталгаажуулсны дараа солино

Код: `src/storage.ts` (унших/бичих, олон цонхны зөрчил), `src/backup.ts` (татах, шалгах), `src/settings.ts`, `src/settings.css`.
