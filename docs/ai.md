# AI зөвлөгөө (Claude)

Нүүр хуудасны «AI зөвлөгөө» таб нь нас, жин, өндөр, онош, тэмдэглэлээс өдрийн усны хэмжээг Claude-оор санал болгоно. Хариуг хэрэглэгч −/+ товчоор засаад зорилт болгож хадгална.

- Хүсэлт `POST /api/plan` руу явна (`backend/src/plan.js`). Сервер хариуг 500–4000 мл-ээр хязгаарлаж, бөөр/зүрхний дутагдалтай бол дээд хязгаар горимд оруулна
- Түлхүүр байхгүй бол API 503 буцааж, таб «AI одоогоор ажиллахгүй» гэж харуулна. Тооцоолох, Эмчийн заавар табууд ердийнхөөрөө ажиллана

## Түлхүүр тохируулах

1. https://console.anthropic.com → **API Keys** → **Create Key**. **Billing** хэсэгт бага хэмжээний кредит нэмнэ
2. Түлхүүрийг backend-ийн secret болгож хийнэ (дахин deploy хийх шаардлагагүй):

   ```sh
   cd backend
   npx wrangler secret put ANTHROPIC_API_KEY
   ```

3. Шалгах: `curl https://dusal-api.bbek3201.workers.dev/api/health` → `{"ok":true,"ai":true}`

Түлхүүрийг код, GitHub, чатанд бүү оруул. Задарсан бол консолоос устгаад шинээр үүсгэж, 2-р алхмыг давтана.

Код: `backend/src/plan.js`, `src/api.ts`, `src/overview.ts`.
