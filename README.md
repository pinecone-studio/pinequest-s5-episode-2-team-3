# Дусал — вэб төслийн суурь

Монгол интерфейстэй усны бүртгэлийн вэбийн Vite суурь. Бүртгэлийн үйлдлүүд дараагийн PR-д орно.

## Ажиллуулах

```sh
bun install
bun run dev
```

Терминалд гарсан локал хаягийг нээнэ.

```sh
bun run build
bun run preview
```

`src/main.js` нь эхлэх цэг, `src/style.css` нь загвар. Энэ repository-д firmware орохгүй.
