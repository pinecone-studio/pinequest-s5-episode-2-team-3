# Ухаалаг суурийн firmware (ESP32-WROOM-32, Bluetooth)

5 кг load cell → HX711 → ESP32-WROOM-32 → OLED + Bluetooth LE → Android апп. Жинг дэлгэцэнд харуулж, уусан хэмжээг өөрөө тоолоод утасны апп руу Bluetooth-ээр илгээнэ. Апп уултыг энгийн бүртгэл болгон хадгалж, одоогийн sync-ээр серверт хүргэнэ. Wi-Fi хэрэггүй.

## Эд анги ба холболт

Бүх код нэг файлд: [`firmware.ino`](firmware.ino). Пинүүдийг файлын эхэн дэх `Settings` хэсэгт өөрчилнө.

| Эд анги | Холболт | `firmware.ino` |
|---|---|---|
| Load cell → HX711 | Улаан E+, Хар E−, Цагаан A−, Ногоон A+ (өнгө үйлдвэрлэгчээс хамаарна) | — |
| HX711 DT (DOUT) | GPIO 16 | `PIN_HX711_DT` |
| HX711 SCK | GPIO 4 | `PIN_HX711_SCK` |
| HX711 VCC / GND | 3.3V / GND | — |
| OLED (NFP1315) SDA / SCL | GPIO 21 / 22, хаяг `0x3C` | `PIN_OLED_SDA`, `PIN_OLED_SCL`, `OLED_I2C_ADDRESS` |
| OLED VCC / GND | 3.3V / GND | — |
| Товч | Самбар дээрх BOOT (GPIO 0) | `PIN_BUTTON` |

A+ ба A− утас солигдсон байсан ч калибровк чиглэлийг өөрөө тохируулна.

OLED дүрс хажуу тийш шилжсэн, нэг талдаа шуугиантай эсвэл огт асахгүй бол модуль нь SH1106 байж магадгүй: `firmware.ino` дахь `OledDisplay`-ийн хоёр дахь мөрийг сонгоно. Дэлгэц олдохгүй бол serial дээр I2C хаягуудыг жагсаана.

## Суулгах

1. [Arduino IDE](https://www.arduino.cc/en/software)-д Boards Manager-оос **esp32 by Espressif** суулгана.
2. Library Manager-оос **HX711 Arduino Library** (Bogdan Necula; Rob Tillaart-ийн "HX711" биш) ба **U8g2** (oliver) суулгана.
3. `firmware/firmware.ino`-г нээж, Tools → Board: **ESP32 Dev Module**, Port-оо сонгоод Upload.
4. Serial Monitor-ийг 115200, "Newline" дээр нээнэ.

Компьютер самбарыг танихгүй бол самбарын USB чипийн драйверийг (CP210x эсвэл CH340) суулгана.

## Калибровк (нэг удаа)

Serial Monitor дээр:

1. Жин дээр юу ч тавихгүйгээр `tare`.
2. Жин нь мэдэгдэж байгаа зүйл тавиад (жишээ нь 500 г) `cal 500`.
3. `status`-аар шалгана. Коэффициент flash-д хадгалагдаж, дахин асахад хэвээр.

Хоосон үед дэлгэц `0.0` гэж харуулна: ±0.5 г доторх жижиг хэлбэлзлийг (`-0.0`, `0.1`) тэг гэж үзнэ (`ZERO_BAND_G`).

### Жин өөрчлөгдөхгүй, калибровк болохгүй бол

Юм тавихад ч жин 0 орчимд хэлбэлзсээр байвал ачаа load cell-д хүрэхгүй байна.

1. Serial Monitor дээр `watch` гэж бичээд 10 секундын турш тавцанг гараараа дарна. `raw` тоо хэдэн мянгаар өөрчлөгдөх ёстой.
2. Бараг өөрчлөгдөхгүй (хэдэн арваар л) бол:
   - load cell-ийн 4 утас HX711-ийн E+, E−, A+, A− руу зөв орсон эсэхийг шалгана;
   - load cell-ийн нэг үзүүр суурьт, нөгөө үзүүр тавцанд шурагдсан, дундаа агаарт байх ёстой; тавцан кейс рүү шүргэж болохгүй.
3. `raw` нь ±8388000 орчим тогтсон байвал HX711 хязгаартаа хүрсэн байна: утас салсан, тасарсан эсвэл буруу пинд байна (`status`, `watch` анхааруулна).
4. Засаад `tare`, дараа нь `cal 500`-г дахин хийнэ.

Ачаа хүрэхгүй үед хийсэн калибровкийг firmware хадгалахгүй, юу шалгахыг serial дээр бичнэ (`MIN_FACTOR`: нэг грамд 20-оос цөөн raw тоо). Өмнө нь ийм буруу калибровк хадгалагдсан бол асахдаа устгаж, дэлгэцэнд «Kalibrovk hii» гэж гаргана.

## Хэрэглэх

- Асахад хоосон жинг тэг гэж авна (tare), тиймээс асаахдаа дээр нь юу ч бүү тавь.
- BOOT товчийг богино дарахад:
  - жин дээр юу ч байхгүй бол дахин тэглэнэ;
  - **хоосон сав** тавьсан бол савны жинг санана. Дэлгэцэнд зөвхөн доторх ус (**Саванд … мл**) харагдаж, апп үлдсэн усыг мэднэ. Савны жин flash-д хадгалагдана.
- Саваа өргөж уугаад буцааж тавина. Суурь тогтворжсоны дараа 3 удаа хэмжиж дундажийг авна (тавьснаас ~1.7 сек). Өмнөхөөсөө 5 г-аас их буурсан бол тэр хэмжээгээр уулт бүртгэгдэнэ (serial: `drink 109 ml (850 -> 741 g)`). 5 г-аас бага өөрчлөлт (жинлүүрийн хэлбэлзэл) нийлж тоологдоно. 2 г-аас бага жин нь «суурь хоосон». Дүүргэх, өргөх үед уулт тоологдохгүй.
- BOOT товч кейс дотор хаагдсан бол апп-ын **Тохиргоо → Bluetooth суурь** хэсгээс ижил зүйлийг хийнэ (`COMMAND_UUID`):
  - **Шинэ сав**: нэр өгөөд хоосон саваа тавьж «Хоосон жинг авах» → суурь жин тогтворжмогц савны жин болгоно; апп нэртэй нь хадгална.
  - **Сав сонгох**: саваа солихоосоо өмнө жагсаалтаас сонгоно → суурь тэр савны жинг авч, сав солилтыг уулт эсвэл дүүргэлт гэж тоолохгүй.
  - «Суурийн жинг тэглэх», «Өнөөдрийн дүнг тэглэх».
- Дэлгэцийн **Уусан** нь апп-ын өнөөдрийн дүн (гараар нэмсэн, устгасан, демо тэглэлт орно); апп холбогдоогүй үед суурь өөрөө тоолсноо нэмнэ.
- 5000 г-аас хэтэрвэл дэлгэцэнд `OVER`.
- Дэлгэцийн зүүн талд Дусал сав хөвж, гараа даллаж, нүдээ ирмэнэ. Баруун талд **Жин** (100 г хүртэл 0.1 г нарийвчлалтай) эсвэл савны жин тохируулсан бол **Саванд … мл**; сав тавьсан ч жин нь тохируулаагүй бол «Савны жинг ав».
- Жин 3 г-аас илүү өөрчлөгдөхөд (сав тавих, өргөх, дарах) дэлгэц асаж, 10 секунд өөрчлөгдөхгүй бол унтарна (`SCREEN_ON_MS`, `SCREEN_WAKE_G`). Хэмжилт, уулт тоолох, Bluetooth унтарсан үед ч ажиллана.
- Дэлгэцийн доод мөрөнд апп холбогдсон бол `BT`, илгээгдээгүй уулт байвал тоо нь (`BT 2` эсвэл `2 hulee`).
- Дэлгэцийн фонт Ө, Ү-гүй тул монгол үгс нь зураг: `text.h` (`python3 firmware/tools/make_text.py`), савны дүр `image.h` (`python3 firmware/tools/make_image.py <зураг.png>`). Pillow хэрэгтэй.
- Serial командууд: `tare`, `cal <грамм>`, `status`, `watch` (10 сек raw утга). `status` нь төхөөрөмжийн ID, савны жин, үлдсэн ус, хүлээгдэж буй уулт, апп холбогдсон эсэхийг харуулна.

BOOT-ийг дарсан чигтээ асааж болохгүй: ESP32 програм суулгах горимд орно. Ийм болвол товчийг тавиад EN (RESET) дарна.

## Bluetooth ба апп

Суурь `Dusal-XXXX` нэрээр Bluetooth LE-ээр харагдана (төхөөрөмжийн ID нь `dusal-xxxx`, serial дээр асахад хэвлэнэ).

1. Android аппыг шинээр суулгана: `bun run android` → Android Studio-д утсаа сонгоод ▶ Run. Bluetooth plugin-гүй хуучин апп ажиллахгүй.
2. Апп → Тохиргоо → **Bluetooth суурь** → **Суурь хайх** → `Dusal-…`-г сонгоно. Bluetooth-ийн зөвшөөрлийг өгнө.
3. Холбогдсоны дараа тохиргоонд жин, үлдсэн ус харагдана. Уулт бүр нүүр хуудсанд «Суурь: … мл ус уулаа» гэж орж ирнэ.

Апп суурийг санаж, нээлттэй үед өөрөө дахин холбогдоно. Chrome хөтөч дээр ч холбогдож болно (iPhone дэмжихгүй).

**Найдвартай байдал.** Уулт бүр flash-д хадгалагдана (64 хүртэл; дүүрвэл хамгийн хуучныг хасна). Апп уултыг хадгалсны дараа батлах хариу бичихэд л суурь түүнийг устгана. Утас хол байх, апп хаалттай байх, суурь унтрах үед уулт алдагдахгүй, холбогдмогц илгээгдэнэ. Уулт бүр `dusal-xxxx-e-<boot>-<n>` гэсэн тогтмол ID-тай тул дахин илгээгдсэн ч давхардахгүй. Суурь цаггүй тул уултын цагийг «хэдэн секундын өмнө» гэж илгээнэ. Суурь унтарч асахаас өмнөх уултын цаг тодорхойгүй тул апп хүлээн авсан цагаар бүртгэнэ.

**Протокол** (апп талд [`src/scale-protocol.ts`](../src/scale-protocol.ts), бүх тоо little-endian):

| Characteristic | UUID | Агуулга |
|---|---|---|
| Service | `d05a1000-6c2b-4b8e-9f3a-2f1e0c7a5b01` | — |
| Status (read, notify, 1 сек тутам) | `d05a1001-…` | flags u8 (bit0 калибровктой, bit1 сав тохируулсан), phase u8 (0 хөдөлж байна, 1 хоосон, 2 сав байна), жин i16 г, үлдсэн ус i16 мл (−1 тодорхойгүй), багтаамж u16 мл, хүлээгдэж буй u8 |
| Drink (read, notify, 3 сек тутам давтана) | `d05a1002-…` | хамгийн хуучин батлагдаагүй уулт: boot u32, n u32, хэмжээ u16 мл, хэдэн секундын өмнө u32 (`0xFFFFFFFF` = тодорхойгүй); байхгүй бол хоосон |
| Ack (write) | `d05a1003-…` | апп хадгалсан уултын boot u32, n u32 |
| ID (read) | `d05a1004-…` | ASCII төхөөрөмжийн ID |

UUID-ууд `firmware.ino` болон апп хоёрт ижил байгааг `bun test tests/scale.test.ts` шалгана. Firmware-ийг компьютер дээр compile хийх: `arduino-cli compile --fqbn esp32:esp32:esp32 firmware`.
