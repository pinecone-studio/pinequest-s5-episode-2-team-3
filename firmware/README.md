# Ухаалаг суурийн firmware (ESP32-S3)

Хүн дурын саваа тавьдаг суурь. Load cell → HX711 → ESP32-S3 → Wi-Fi → backend → апп. Суурь уусан хэмжээг өөрөө тоолж, дараалалд хадгалаад серверт илгээнэ. API-ийн дүрэм: [docs/device-ingestion.md](../docs/device-ingestion.md).

## Эд анги ба холболт

Пинүүдийг `include/config.h`-д нэг газар өөрчилнө. Доорх нь ESP32-S3 DevKitC-ийн анхны утга; өөр самбар бол самбарынхаа pinout-оор солино.

| Эд анги | Холболт | `config.h` |
|---|---|---|
| Load cell → HX711 | E+/E−/A+/A− (load cell-ийн утасны өнгө үйлдвэрлэгчээс хамаарна) | — |
| HX711 DT | GPIO 4 | `PIN_HX711_DT` |
| HX711 SCK | GPIO 5 | `PIN_HX711_SCK` |
| HX711 VCC/GND | 3.3V / GND | — |
| OLED SSD1306 SDA / SCL | GPIO 8 / 9, хаяг `0x3C` | `PIN_OLED_SDA`, `PIN_OLED_SCL`, `OLED_I2C_ADDRESS` |
| Товч | Самбар дээрх BOOT (GPIO 0) | `PIN_BUTTON` |
| LiPo | Самбарын цэнэглэх хэлхээгээр | — |

Тэжээл, пиний холболтыг самбар болон модулийн үйлдвэрлэгчийн баримттай тулгаж шалгана. Энэ код батарейн түвшин хэмждэггүй.

## Суулгах

1. [PlatformIO](https://platformio.org/install) суулгана (VS Code-ийн PlatformIO IDE эсвэл `pip install platformio`).
2. `include/secrets.example.h`-г `include/secrets.h` болгон хуулж Wi-Fi, `DEVICE_ID`, `DEVICE_TOKEN`-оо бөглөнө. `secrets.h` Git-д орохгүй.
3. Серверт ижил түлхүүрийг бүртгэнэ: `DEVICE_TOKENS` secret-д `{"base-01":"<түлхүүр>"}` ([заавар](../docs/device-ingestion.md#төхөөрөмжийн-түлхүүр)).
4. `firmware/` дотор: `pio run -t upload`, дараа нь `pio device monitor`.

`API_ROOT_CA` хоосон бол HTTPS сертификат шалгахгүй (зөвхөн прототип: сүлжээн дээрх хэн нэгэн түлхүүрийг харж болно). Бодит хэрэглээнд API хостын root сертификатыг PEM-ээр оруулна.

## Анх калибровк хийх (нэг удаа)

Serial monitor (115200) дээр:

1. Суурийг хоосон байлгаад `zero` (эсвэл BOOT-ийг 5 сек дарна).
2. Жин нь мэдэгдэж байгаа зүйл тавиад (жишээ нь 500 г ус) `cal 500`.
3. `status`-аар шалгана. Утгууд flash-д хадгалагдаж, дахин асахад хэвээр.

## Хэрэглэх

- **Шинэ сав:** хоосон саваа тавиад, тогтворжтол хүлээгээд BOOT-ийг богино дарна. Үүний дараа үлдэгдэл мл-ээр харагдана. Дарахгүй бол уулт тоологдсоор, үлдэгдэл `?`.
- Саваа өргөж уугаад буцааж тавина. Жин буурсан хэмжээгээр уулт бүртгэгдэнэ. Дүүргэхэд уусан нийлбэр нэмэгдэхгүй.
- Асгасан бол апп дээр бүртгэлийг «Асгасан» болгоно.
- OLED: үлдэгдэл, сүүлийн уулт, Wi-Fi/цаг, илгээгдээгүй уултын тоо. Үсэг латинаар (дэлгэцийн фонт кирилл дэмждэггүй).

Serial командууд: `zero`, `cal <грамм>`, `tare`, `raw`, `status`.

BOOT-ийг дарсан чигтээ асааж болохгүй: ESP32 програм суулгах горимд орно. Ийм болвол товчийг тавиад RESET дарна.

## Найдвартай байдал

- Уулт бүр flash-д хадгалагдсаны дараа илгээгдэнэ; серверээс 2xx ирэхэд устана. Сервер хэзээ ч хүлээж авахгүй хариу (400/409/413) ирвэл бусад уултыг хаахгүйн тулд хасаж, serial дээр бичнэ. Интернет тасрах, дахин асах үед алдагдахгүй, давхардахгүй.
- 128 хүртэл илгээгдээгүй уулт хадгална; дүүрвэл хамгийн хуучныг хасаж OLED дээр `lost` гэж тоолно.
- Цаг NTP-ээс (UTC). Цаг тохирохоос өмнөх уултад цаг тохирмогц асалтаас хойшх хугацаагаар зөв цаг өгнө; цаг тохирохоос өмнө дахин унтарсан бол тохирсон мөчийн цагийг авна.

## Тест

```sh
bun run test:firmware   # repo root: тооцоолол, дараалал, JSON, дэлгэц + Worker-тэй нийцэл
```

Компьютер дээр зөвхөн `lib/dusal_core` (Arduino-гүй) хэсэг шалгагдана. GitHub дээр `firmware/` өөрчлөгдсөн PR бүрд эдгээр тест болон ESP32-S3-ийн бүтэн compile автоматаар ажиллана (`.github/workflows/firmware.yml`). `src/main.cpp` (HX711, Wi-Fi, HTTPS, OLED)-ийг `pio run`-аар compile хийж, бодит суурь дээр туршина. Босго утгууд (`intake.h`: 10 г, 4 г, 1.5 сек) прототипийнх; бодит load cell-ийн хэлбэлзлийг хэмжиж тохируулна.
